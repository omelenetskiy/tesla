## Key Behavioral Changes for Users

### Before → After

| Aspect | Before | After |
|--------|--------|-------|
| **Authentication** | Owner API OAuth (password flow risk) | Fleet API OAuth (PKCE, zero-trust) |
| **Vehicle Data** | Polling every 5 min (inefficient) | Fleet Telemetry stream (real-time) |
| **Real-time Stream** | Fetch + parse | mTLS direct from Tesla cloud → Oracle |
| **Access Requirement** | Account only | Account + Fleet Token |
| **Data Age** | 5–60 seconds old | <1 second old (live) |
| **Secret Rotation** | App password exposure risk | Refresh tokens (opaque, rotated by Tesla) |
| **Compliance** | Owner API (deprecated) | Fleet API (recommended, future-only) |
