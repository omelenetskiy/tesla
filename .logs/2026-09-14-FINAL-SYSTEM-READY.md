## 🚀 ЧТО ПРОИСХОДИТ СЕЙЧАС

1. **Автомобиль** Tesla Model Y отправляет телеметрию на `telemetry.omelenetskiy.xyz:443`
2. **Fleet Telemetry Server** получает и обрабатывает данные
3. **Server** логирует входящие соединения и события
4. **Фронтенд** может запросить данные через Tesla Fleet API
5. **Dashboard** отобразит реальное состояние автомобиля
