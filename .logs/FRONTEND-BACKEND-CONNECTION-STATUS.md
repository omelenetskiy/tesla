```
ВАШЕ ПРИЛОЖЕНИЕ (tesla-y-dashboard.netlify.app)
```

## ✨ ЧТО ПРОИСХОДИТ ТЕХНИЧЕСКИ

1. **Ваша машина включена** → Система пробуждается
2. **Машина подключается к интернету** (мобильный 4G/LTE)
3. **Инициирует mTLS соединение** к telemetry.omelenetskiy.xyz:443
4. **Отправляет данные телеметрии** (GPS, батарея, скорость)
5. **Сервер телеметрии получает** и логирует
6. **Fleet API Tesla получает доступ** к этим данным
7. **Ваше приложение запрашивает** через Fleet API
8. **Получает JSON ответ** с данными машины
9. **Отображает на Dashboard** 📊
