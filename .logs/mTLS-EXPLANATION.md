## 🔐 Что Такое mTLS?

### Обычный TLS (HTTPS)

```
Браузер                              Сервер
   │                                   │
   │  ← ← ← Предоставить сертификат   │
   │  (Браузер верит серверу)         │
   │                                   │
   └─ Браузер проверяет сертификат ───→
```

Только **сервер** доказывает, что он легитимный.

### mTLS (Mutual TLS)

```
Клиент                              Сервер
   │                                   │
   │  ← ← ← Предоставить сертификат   │
   │  (Сервер требует это)            │
   │                                   │
   │  ← ← ← Сервер ждет клиентский    │
   │        сертификат                │
   │                                   │
   │  Предоставить мой сертификат ─ ─→│
   │  (Сервер верит клиенту)         │
   │                                   │
   └── ДВУСТОРОННЯЯ аутентификация ───→
```

**Оба** стороны доказывают, что они легитимные!

## ✅ ВАШ КОНФИГ ПРАВИЛЬНЫЙ

В `config.local.json`:

```json
"tls": {
  "server_cert": "/etc/fleet-telemetry/certs/fullchain.pem",
  "server_key": "/etc/fleet-telemetry/certs/privkey.pem"
}
```

✅ **Tesla Fleet Telemetry ПО УМОЛЧАНИЮ требует mTLS**

Это встроено! Вам не нужно ничего дополнительно конфигурировать.
